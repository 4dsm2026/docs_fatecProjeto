# Permissões de acesso

Em **Configurações**, a tabela **Permissões de acesso** mostra o que cada perfil pode fazer no sistema.

![Permissões de acesso](/img/manual/admin-12-configuracoes.webp)

- Cada linha é um **recurso ou ação** (ex.: ver chamados, alterar status, cadastrar alunos).
- As colunas são os perfis: **Usuário (Aluno)**, **Backoffice**, **Técnico** e **Administrador**.
- Use o filtro para encontrar um recurso ou rota (ex.: `chamado`, `/usuarios`).

A tabela é apenas para consulta. As permissões são definidas no sistema; para mudar uma regra, abra uma issue no [GitHub](https://github.com/4dsm2026/backend_fatecProjeto/issues/new/choose).
