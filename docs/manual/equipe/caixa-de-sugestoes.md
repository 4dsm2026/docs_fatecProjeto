# Responder sugestões

As sugestões, elogios e críticas enviados pelos alunos ficam em **Caixa de Sugestões**.

![Lista de sugestões](/img/manual/admin-08-sugestoes.webp)

Filtre por **Não respondido** para ver o que está pendente.

## Responder

![Responder uma sugestão](/img/manual/admin-09-sugestao-detalhe.webp)

1. Abra a sugestão.
2. Escreva a resposta no editor.
3. Mude o status para **Respondido**.
4. Clique em **Salvar**.

:::caution A resposta não pode ser editada
Depois de salva, a resposta fica fixa, e uma sugestão marcada como **Respondido** não pode mais ter a resposta nem o status alterados. Revise antes de salvar.
:::
