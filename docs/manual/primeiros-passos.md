# Primeiros passos

## Entrar no sistema

![Tela de login com as abas Funcionário e Aluno (RA)](/img/manual/aluno-01-login.webp)

1. Escolha a aba de acordo com o seu perfil:
   - **Funcionário**: entre com o **e-mail institucional** (ex.: `nome.sobrenome@fatec.sp.gov.br`).
   - **Aluno (RA)**: entre com o seu **RA**.
2. Digite a senha (mínimo de 8 caracteres). O ícone de olho mostra ou esconde a senha.
3. Clique em **Entrar**.

O sistema leva cada perfil para a sua área: alunos para o **Portal do Aluno**, funcionários para o painel da **Secretaria**.

:::caution Bloqueio por tentativas
Depois de **5 senhas erradas seguidas**, a conta fica bloqueada por **15 minutos** e desbloqueia sozinha. Se não lembrar a senha, use **Esqueci a senha** antes de chegar ao bloqueio.
:::

## Primeiro acesso

Contas novas recebem uma **senha temporária**. No primeiro login com ela, o sistema pede a troca da senha antes de liberar o acesso.

![Tela de primeiro acesso](/img/manual/aluno-02-primeiro-acesso.webp)

1. Opcionalmente, informe um **e-mail pessoal**. Ele é usado para recuperar a senha e receber avisos.
2. Crie a **nova senha** e repita-a em **Confirmar nova senha**. A senha precisa ter:
   - pelo menos 8 caracteres;
   - uma letra maiúscula e uma minúscula;
   - um número;
   - um símbolo (ex.: `!`, `@`, `#`).
3. Clique em **Concluir primeiro acesso**. Você já entra no sistema.

## Esqueci a senha

1. Na tela de login, clique em **Esqueci a senha**.
2. Informe o seu e-mail. Você recebe um link para criar uma nova senha.
3. Não chegou? Confira a caixa de spam e se o e-mail cadastrado em **Meus dados** está correto. Se ainda assim não funcionar, procure a secretaria.

## No dia a dia

- **Sair**: botão **Sair**, no fim do menu lateral. Use sempre que estiver em um computador compartilhado.
- **Modo escuro**: ícone de lua, no canto superior direito.
- **Notificações**: ícone de sino, no canto superior direito. O número vermelho indica avisos não lidos.
- **Cookies**: no primeiro acesso a cada navegador aparece um aviso. **Somente essenciais** mantém apenas o necessário para o sistema funcionar.
- **Celular**: o sistema funciona no navegador do celular. O menu fica no botão **Menu**.
