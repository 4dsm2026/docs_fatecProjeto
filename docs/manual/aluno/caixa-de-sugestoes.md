# Caixa de Sugestões

Use a **Caixa de Sugestões** para enviar uma sugestão, um elogio ou uma crítica à Fatec. Ela não serve para pedidos: para isso, [abra uma solicitação](./abrir-solicitacao.md).

![Formulário da Caixa de Sugestões](/img/manual/aluno-11-sugestoes-nova.webp)

## Enviar uma sugestão

1. Confira o **R.A.**, preenchido automaticamente.
2. Informe um **e-mail** para contato (obrigatório).
3. Escreva a **sugestão** (até 1000 caracteres). A barra de ferramentas permite negrito, listas, links, imagens e tabelas.
4. Clique em **Enviar**.

:::caution Depois de enviada, a sugestão não pode ser editada
Revise o texto antes de clicar em **Enviar**.
:::

## Acompanhar a resposta

As sugestões aparecem em **Sugestões enviadas**, com o status:

- **Não respondido**: a equipe ainda não respondeu;
- **Respondido**: abra a sugestão para ler a resposta.

![Sugestões enviadas, com o status](/img/manual/aluno-13-sugestoes-lista.webp)
