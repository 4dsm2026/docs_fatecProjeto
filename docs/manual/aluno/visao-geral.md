# Visão geral do Portal do Aluno

Depois de entrar, você chega à **Visão Geral**: um resumo das suas solicitações.

![Visão Geral do Portal do Aluno](/img/manual/aluno-03-visao-geral.webp)

## Os quatro indicadores

| Indicador | O que conta |
|---|---|
| **Recebidas** | Todas as solicitações que você abriu |
| **Aguardando minha ação** | Solicitações em que a Fatec precisa de algo seu: responda ou anexe o que foi pedido |
| **Em análise** | Solicitações que alguém da equipe está atendendo |
| **Respondidas** | Solicitações concluídas |

Abaixo, **Solicitações em aberto** lista o que ainda está em andamento. **Ver detalhes** abre a solicitação; **Ver todas** leva para [Minhas solicitações](./acompanhar-solicitacoes.md).

:::tip Fique de olho em "Aguardando minha ação"
Se esse número for maior que zero, a secretaria está esperando por você. A solicitação só anda quando você responder.
:::

## Menu

| Item | Para quê |
|---|---|
| **Visão Geral** | Esta página |
| **Minhas solicitações** | Lista completa, com busca e filtro por status — [Acompanhar solicitações](./acompanhar-solicitacoes.md) |
| **Catálogo de serviços** | Abrir uma nova solicitação — [Abrir uma solicitação](./abrir-solicitacao.md) |
| **Meus dados** | Dados pessoais, contato e senha — [Meus dados e configurações](./meus-dados-e-configuracoes.md) |
| **Notificações** | Avisos sobre as suas solicitações — [Notificações](./notificacoes.md) |
| **Caixa de Sugestões** | Enviar sugestões, elogios ou críticas — [Caixa de Sugestões](./caixa-de-sugestoes.md) |
| **Ajuda / FAQ** | Respostas para as dúvidas mais comuns |
| **Configurações** | Tema e notificações |

## No celular

O portal se adapta à tela do celular. O menu fica no botão **Menu**, logo abaixo da saudação.
