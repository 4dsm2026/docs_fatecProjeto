# 📋 Criação de Issues e Pull Requests

O guia de contribuição agora é **único para toda a organização** e fica no repositório [`4dsm2026/.github`](https://github.com/4dsm2026/.github):

👉 **[Abrir o guia de contribuição](https://github.com/4dsm2026/.github/blob/main/CONTRIBUTING.md)**

Ele reúne:

- formato do título (`[Tipo] Descrição`) e as **4 labels** obrigatórias das issues;
- nomes de branch (`<tipo>/issue-<número>-<descrição>`);
- como abrir Pull Requests vinculados à issue (`Closes #N`);
- padrão de commits, sprints e versões.

Ao clicar em **New issue** em qualquer repositório, o GitHub já mostra os modelos (Bug, Nova funcionalidade, Tarefa técnica).
